# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница;
- `css/style.css` — файл стилей;
- `js/main.js` — логика модального окна и валидации формы;
- `images/` — папка для изображений;
- `tests/` — автоматические проверки разметки, JavaScript и CSS в браузере;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Реализованные элементы интерфейса

- кнопки «Заказать» в карточках товаров;
- модальное окно на основе элемента `dialog`;
- форма с полями имени, e-mail, телефона, даты, темы и комментария;
- обязательное согласие на обработку персональных данных;
- подсветка полей с ошибками;
- сообщение об успешной отправке формы.

Форма пока работает в демонстрационном режиме: данные не отправляются на сервер и не сохраняются.

## CSS-архитектура

Файл `css/style.css` разделён на пять смысловых блоков: переменные, базовые стили, общие элементы интерфейса, компоненты страницы, форма и модальное окно.

- В `:root` определены цвета (`--color-*`), единая шкала отступов (`--space-*`), скругления (`--radius-*`) и размеры контейнера и диалога.
- Значения используются через `var()`: изменение переменной меняет все связанные компоненты.
- Ссылки, кнопки, карточки и поля реагируют на `:hover`.
- Поля имеют состояние `:focus`, а ссылки, кнопки и поля — видимый `:focus-visible` для клавиатурной навигации.
- Отключённые кнопки и поля оформлены через `:disabled`; наведение не делает их похожими на активные.
- Ошибочные поля выделяются через `aria-invalid="true"`, без `!important`; цвет ошибки сохраняется при наведении и фокусе.

Проверка вручную: открыть `index.html`, пройти по элементам клавишей Tab, открыть «Заказать» и отправить пустую форму. Для проверки отключённой кнопки в DevTools временно добавить ей атрибут `disabled`, затем убрать его. Кнопки сайта по умолчанию остаются активными.

## Автоматические проверки

```sh
python3 -m unittest discover -s tests -p 'test_*.py'
node --test tests/main.test.mjs
```

Для браузерных проверок нужен Playwright и его Chromium (только для тестирования, не для работы сайта):

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node --test tests/styles.test.mjs
```
