## Что показать по порядку

1. Открыть главную и каталог. Показать одинаковое меню на всех пяти страницах.
2. Из каталога нажать «Популярные товары»: откроется index.html#popular.
   URL содержит якорь, раздел выделен пунктиром. Нажать другие ссылки к разделам.
3. На внутренней странице показать «Главная / Каталог» — хлебные крошки.
   «Главная» ведёт назад; текущая страница не является ссылкой.
4. В HTML показать nav, href, id, один main, уникальные title и meta description.
5. В каталоге показать фильтры слева, карточки справа. Фильтры — только макет;
   галочки и цена вводятся, но отключённая кнопка не фильтрует список.
6. В DevTools открыть .catalog-layout: display: grid, две колонки,
   grid-template-areas: "filters products". Включить Grid overlay.
7. Открыть .product-grid: три колонки. Затем .product-card: display: flex,
   flex-direction: column; .product-card__actions: margin-top: auto.
   С длинным описанием действия всё равно находятся внизу карточек.
8. Показать .site-nav__list: Flex, wrap, center, gap. Сузить окно:
   меню переносится, а при ширине до 700px каталог становится одноколоночным.
9. На GitHub показать README, историю его коммитов, обе feature-ветки,
   Pull Request в main и опубликованный сайт.

## №5: понятия и ответы

- **Многостраничный сайт (MPA):** отдельные HTML-документы, переходы между ними
  загружают другую страницу. У нас index, catalog, product, order, contacts.
- **Ссылка:** a с href. catalog.html открывает файл, #popular — раздел
  текущего документа, index.html#popular — раздел другого документа.
- **id:** уникальный идентификатор элемента в пределах страницы. Якорь
  после # должен совпадать с id цели.
- **Единая навигация:** одинаковый набор ссылок на всех страницах помогает
  пользователю не потеряться. aria-current="page" отмечает текущую страницу.
- **nav:** семантическая область навигации. Меню и хлебные крошки —
  разные nav с разными aria-label.
- **main:** основное содержимое страницы; один видимый main на документ.
- **Хлебные крошки:** показывают путь в структуре сайта. «Главная / Каталог».
  Текущая страница — span, поскольку переходить на неё саму незачем.
- **title:** название документа во вкладке браузера; у каждой страницы своё.
- **meta description:** краткое описание страницы для поисковых систем;
  это не видимый текст страницы и не гарантия текста поискового сниппета.
- **scroll-behavior: smooth:** плавная прокрутка к якорю. При пользовательском
  prefers-reduced-motion: reduce она отключается.
- **:target:** CSS-псевдокласс элемента, id которого совпадает с текущим
  фрагментом URL. У нас добавляет пунктирный outline, не меняя размер блока.
- **Дополнительное SEO:** sitemap и OpenGraph не нужны для базового выполнения
  этой практики; сначала важны корректные страницы и рабочие переходы.

## №6: понятия и ответы

- **Flexbox:** раскладка преимущественно вдоль одной оси — строка либо колонка.
  Удобен для меню и содержимого карточки.
- **Grid:** двумерная сетка, одновременно организует строки и колонки.
  Удобен для каталога с боковой панелью и рядами карточек.
- **display: flex / grid:** делает элемент контейнером соответствующей раскладки;
  его непосредственные дети становятся flex/grid-элементами.
- **flex-direction: column:** главная ось идёт сверху вниз.
- **justify-content:** выравнивает элементы вдоль главной оси.
  В меню center размещает группу ссылок по центру горизонтально.
- **align-items:** выравнивает элементы по поперечной оси.
  В строке меню center — по вертикали.
- **flex-wrap: wrap:** разрешает перенос элементов на следующую строку.
- **gap:** расстояние между соседними элементами раскладки, не внешний отступ.
- **grid-template-columns:** задаёт количество и размеры колонок.
  В каталоге 260px — фильтры, minmax(0, 1fr) — оставшееся место для товаров.
- **fr:** доля свободного пространства сетки, а не процент ширины страницы.
- **repeat(3, ...):** повторяет описание колонки три раза.
- **minmax(0, 1fr):** минимум 0, максимум доля свободного места; нулевой минимум
  позволяет колонке сжиматься, не упираясь в минимальную ширину содержимого.
- **grid-template-areas:** задаёт именованные области контейнера.
  "filters products" — два участка в одной строке.
- **grid-area:** связывает дочерний элемент с именем области:
  .catalog-filters получает filters, .catalog-products получает products.
- **margin-top: auto:** в вертикальной flex-карточке поглощает свободное место
  над блоком действий и прижимает его вниз.
- **Почему вместе:** Grid организует внешний каркас, Flex — внутренний поток.
  Они не конкурируют и могут быть вложены друг в друга.
- **Адаптивность:** изменение раскладки под размеры экрана. Полная адаптация —
  отдельная тема; здесь сохранён простой существующий breakpoint 700px.
- **БЭМ:** правило именования классов, а не способ раскладки. Например,
  product-card — блок, product-card__title — элемент, button--secondary —
  модификатор. И Flex, и Grid могут применяться к БЭМ-классам.

## Git и README

- Ветка изолирует набор изменений.
- Коммит — сохранённый снимок изменений; push отправляет его на GitHub.
- Pull Request показывает разницу и предлагает объединить ветку с main.
- Merge объединяет изменения. GitHub Pages публикует main.
- README описывает запуск, структуру, ограничения и выполненные требования.
- Для демонстрации коммитов: git log --oneline -- README.md.

Не обещать сервер, сохранение заявок, оплату или работающую фильтрацию:
их здесь нет. БЭМ, fixed и базовая сетка были сделаны раньше в контрольной;
новое в №6 — именованные области и внутренняя Flex-раскладка карточек.
