# Контрольная работа №1 — DeskSupply

Автор: Чернышев Антон Дмитриевич, ЭФБО-02-25.

## Результат

Расширить существующий учебный проект практик 1–4 до статического
многостраничного магазина аксессуаров для рабочего места. Сохранить
примеры семантики, валидации и модального dialog. Выполнить обязательные
требования PDF, не исключая неизвестные «2 из 3».

Пять страниц: главная, каталог, товар (клавиатура), заявка, контакты.
На каждой — одинаковая навигация с текущим пунктом, header/nav/main/footer,
уникальные title и description, общий CSS.

Каталог: три полноценных товара с иллюстрациями, ценами, карточками article,
ссылками на описания. Главная: преимущества, популярные товары, FAQ.
Карточка клавиатуры: характеристики в доступной таблице. Заявка:
имя, email, телефон, тема, комментарий, согласие; учебная проверка без
отправки, хранения, корзины или оплаты. Контакты явно демонстрационные.

## Оформление и ограничения

Собственная спокойная визуальная концепция: тёмно-синий текст, тёплый светлый
фон, зелёный акцент, локальные SVG-иллюстрации. БЭМ, переменные, Flex и Grid,
hover/focus-visible/disabled, relative/absolute/sticky/fixed и z-index.
Без CSS-фреймворков, сборщика, сторонних шрифтов и полноценных JS-функций.
Минимальный существующий JS отвечает только за dialog и проверку формы.
Простая адаптация предотвращает переполнение; сложная адаптивность не
подменяет будущую КР №3.

README: описание, структура, запуск, автор, Pages, карта обязательных
требований и собственных улучшений; отдельная памятка с 22 вопросами защиты.
Изменения README — отдельный коммит, доступный в истории GitHub.

## Проверка

Структурные тесты всех страниц и локальных ссылок; Chromium: навигация,
Grid/Flex, диалог, невалидная и валидная заявка без сетевой отправки.
Проверка скриншотов, отсутствие переполнения на узком экране.
Публикация в существующий GitHub Pages после тестов и независимого ревью.
СДО не отправляется автоматически.
